# cinesphere

A sleek and interactive movie search application built using HTML, CSS, and vanilla JavaScript. The app connects to a live movie database API to let users query titles, fetch real-time film data, and browse current trending showcases.

## Features

* **Movie Search:** Query live databases to find specific titles, release years, and user ratings instantly.
* **Trending Showcases:** Dynamically populates the homepage with current top-performing and popular motion pictures.
* **Interactive UI:** Features card-based layouts and smooth transitions designed for clean media browsing.
* **Responsive Design:** Adapts naturally across mobile layout screens, tablets, and desktop displays.

## Project Structure

```text
├── assets/        # Visual media, logos, and iconography assets
├── index.html     # Semantic webpage markup layout
├── style.css      # User interface layouts and adaptive query styles
├── script.js      # Asynchronous API data fetching and DOM injection
└── readme.md      # Project documentation
```

## How to Run It

1. Click the green **Code** button at the top of this GitHub page and select **Download ZIP**.
2. Extract the downloaded ZIP file onto your local computer storage.
3. Open the folder and double-click the `index.html` file to run the app directly in your web browser. No local installation or servers needed.
